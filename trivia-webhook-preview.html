🎯 Trivia Lead Webhook Integration

This page shows how the trivia lead webhook works and what data is sent when a user completes the trivia game.

⚠️ Environment Variable Required:
Add your webhook URL to server/.env:
TRIVIA_WEBHOOK_URL="https://your-webhook-endpoint.com/webhook"

📊 JSON Payload Structure

The following JSON data will be sent to your webhook:

{
  "event": "trivia_lead_captured",
  "timestamp": "2025-01-26T10:30:45.123Z",
  "lead": {
    "name": "John Smith",
    "email": "john@example.com",
    "interests": [
      "Vegetables",
      "Cannabis",
      "Landscaping"
    ],
    "score": 4,
    "answers": [0, 2, 3, 1, 2],
    "submittedAt": "2025-01-26T10:30:45.123Z",
    "eventName": "Trade Show 2025",
    "prizeCode": "SOIL20",
    "leadQuality": "hot",
    "engagementLevel": "high"
  },
  "emailHtml": "<!DOCTYPE html>..."
}

📈 Lead Scoring Logic

Lead Quality:

  • 🔥 Hot Lead: Score 4-5 out of 5
  • 🟡 Warm Lead: Score 3 out of 5
  • ❄️ Cold Lead: Score 0-2 out of 5

Engagement Level:

  • High: Selected 4+ interests
  • Medium: Selected 2-3 interests
  • Low: Selected 0-1 interests

Available Interests:

  • 🥬 Vegetables
  • 🌿 Cannabis
  • 🌳 Landscaping
  • 🪴 Indoor Plants
  • 🌱 Lawn Care
  • 🍃 Native Plants

🔧 Webhook Integration Examples

Make.com (Integromat) Setup:

  1. Create a new scenario
  2. Add a "Webhooks" trigger
  3. Copy the webhook URL
  4. Add to your .env file
  5. Process the JSON data as needed

Zapier Setup:

  1. Create a new Zap
  2. Choose "Webhooks by Zapier" trigger
  3. Select "Catch Hook"
  4. Copy the webhook URL
  5. Add actions (email, CRM, etc.)

📝 Testing the Webhook

To test the webhook integration:

  1. Add your webhook URL to server/.env
  2. Restart the server
  3. Complete the trivia game at /trivia
  4. Check your webhook endpoint for the incoming data

Test webhook services:

  • webhook.site - Free webhook testing
  • RequestBin - Inspect HTTP requests
  • ngrok - Local webhook testing
