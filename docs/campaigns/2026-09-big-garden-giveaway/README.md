## Campaign path

1. Run one no-purchase-necessary giveaway to collect qualified Phoenix garden leads.
2. Ask what each entrant grows and whether the garden is new or existing.
3. Select one winner under written official rules.
4. Give every non-winner a 72-hour offer:
   - Garden Refresh — $99
   - Garden Refresh Plus — $149
   - Big Garden Setup — $399
5. Call only the highest-intent 10–15% of entrants.

Public language: **giveaway** or **sweepstakes**, not raffle.
